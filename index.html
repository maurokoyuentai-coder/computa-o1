DÚVIDAS

Perguntas frequentes.

O projeto está sendo construído por etapas. Esta versão já permite testar a experiência das ferramentas diretamente no navegador.

Preciso entender de inteligência artificial? +

Não. A proposta é justamente transformar tarefas comuns em formulários simples, reduzindo a necessidade de criar prompts do zero.

As respostas já usam uma IA real? +

Nesta versão, os resultados são gerados localmente pelo próprio site. Isso permite testar o fluxo antes da integração com uma API de inteligência artificial.

Posso usar no celular? +

Sim. O layout foi preparado para telas menores e o modal das ferramentas se adapta ao celular.

O resultado pode ser editado? +

Sim. O objetivo é fornecer uma base. Você pode copiar o resultado e alterar qualquer trecho antes de usar.
